# Local benchmark results

These are measurements from the Docker Compose stack on 2026-08-07 UTC. They are
local-environment evidence, not production capacity or uptime claims.

## API load test (k6)

The test exercised authenticated `GET /api/v1/auth/me` and `GET /api/v1/orgs`.
Each run created one test account and used a one-second pacing delay per VU.

| Concurrent VUs | Duration | HTTP requests | Throughput | P95 latency | HTTP failures |
|---:|---:|---:|---:|---:|---:|
| 20 | 30 s | 1,201 | 39.00 req/s | 27.25 ms | 0.00% |
| 50 | 30 s | 3,001 | 98.20 req/s | 12.47 ms | 0.00% |

The custom authenticated-route trend was 27.21 ms P95 at 20 VUs and 12.45 ms
P95 at 50 VUs. Both runs passed the configured k6 thresholds.

## Kafka audit recovery

The standalone audit consumer was stopped, an `ORG_CREATED` event was published
by the backend, and the consumer was restarted. The event was persisted to the
separate `audit-postgres` database after **17.614 s**. This verifies queued-event
recovery for this single-event local test; it does not prove zero loss under all
failure modes.

## Product/security snapshot

The database snapshot generated by `scripts/generate-impact-report.sh` recorded:

- 24 registered users and 15 organizations
- 11 collections and 13 saved endpoints
- 13 request runs, 53.85% success rate
- response-time P50 32.00 ms and P95 517.40 ms
- 3 best-effort SSRF/invalid-URL blocks

These counts reflect retained local test data only.

## Resource snapshot

An idle post-test Docker snapshot showed backend memory at 388.3 MiB, Redis at
3.934 MiB, PostgreSQL at 36.27 MiB, Kafka at 209.4 MiB, and audit-service at
314 MiB. CPU was below 1% for each sampled container; this is not a peak-load
measurement.

## Not measured yet

Exact Redis cache-hit rate/uncached-vs-cached delta, Kafka events/sec and lag,
indexed-vs-unindexed query comparison, and a controlled circuit-breaker test
are not exposed by the current benchmark harness. No numbers are assigned to
those metrics.

## Reproduce

```bash
docker run --rm --network host \
  -v "$PWD/qa/impact:/scripts:ro" \
  -v "$PWD/artifacts/impact:/results" \
  -e BASE_URL=http://127.0.0.1:8080 \
  -e VUS=50 -e DURATION=30s \
  grafana/k6:latest run \
  --summary-export /results/k6-50vus-30s.json \
  /scripts/performance.k6.js

./scripts/generate-impact-report.sh
```
